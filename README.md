# Equity Administration Competitive Analysis

This repository contains interactive visualizations and analysis for equity administration systems.

## Pages

- **index.html** - Main landing page
- **jpms_capability_map_4.html** - JPMS Capability Map
- **competitive-landscape.html** - Competitive Landscape Analysis
- **integration-story.html** - Integration Story
- **integration-data-flow.html** - Integration Data Flow
- **battlecard.html** - Battlecard

## Viewing

`https://<your-username>.github.io/Equity-Administration-Competitive-Analysis-main/`
